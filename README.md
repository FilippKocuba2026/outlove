# OutLove • Социальная сеть знакомств

Полностью функциональное демо-приложение социальной сети знакомств на чистом HTML + Tailwind CSS + JavaScript.

## Особенности

- Свайп-карточки с поддержкой touch и мыши
- Система лайков и матчей с красивой анимацией
- AI Love Coach с памятью разговора
- Чаты с авто-ответами
- Модальные окна (профиль, Premium, верификация, фильтры)
- Реальная интеграция погоды (Open-Meteo API)
- Запись видео-интро из камеры
- OAuth симуляция (ВК, Яндекс) + CSRF защита
- Режим инкогнито, достижения, реферальная программа

## Как запустить

1. Откройте `index.html` в браузере
2. Или посетите на GitHub Pages (см. ниже)

## GitHub Pages (рекомендуется)

1. Зайдите в **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main`, Folder: `/ (root)`
4. Нажмите Save
5. Через 1–2 минуты демо будет доступно по ссылке:
   **https://filippkocuba2026.github.io/outlove/**

## Технологии

- Tailwind CSS (CDN)
- Font Awesome 6
- Чистый JavaScript (localStorage, MediaRecorder, Geolocation, Clipboard API)
- Glassmorphism + современные анимации 2026 года
